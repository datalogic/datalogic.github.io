Scanner Options

Use this settings to configure the good read tone and display notification.

Tap Scanner Options to customize the device scanning behavior.

Enable Scanner​

Enables the internal scanner.

Scanner/Camera Interoperability​

By default, the scanner is prevented from starting barcode scanning when the camera is in preview. This setting enables interoperability between the scanner and other cameras, allowing the user to scan barcodes even while another camera is in use.

Enhance DoF​

If enabled, allows to enhance the maximum reading distance.

Enable picklist​

If enabled, it allows you to pick and decode a barcode from multiple barcodes printed close together, when the scan illumination intersects more than one barcode. Only the targeted barcode will be returned.

Enable illumination​

If enabled, it causes the scanner to turn on the illumination to aid decoding.

Illumination intensity​

Adjusts the brightness of the scanner’s illumination from 1% to 100%. Lower values reduce glare on reflective surfaces, while higher values improve readability in dark environments.

Enable aim​

Enables the laser aim.

Display mode (Antireflex)​

Optimizes the reading of a barcode from a screen.

Scan mode​

Selects the scan operating mode for the reader.

OptionDescription
SingleWhen the trigger is pulled, scanning is activated until one of the following occurs:
• a label has been read
• the trigger is released
• the decode timeout has elapsed.
Hold MultipleWhen the trigger is pulled, the device scans barcodes until the trigger is released or the decode timeout has elapsed.
Pulse MultipleWhen the trigger is pulled, continuous scanning is activated until the decode timeout has elapsed or the trigger has been released and pulled again.
Always OnNo trigger pull is required to read a barcode. Scanning is continually on.

Double read timeout​

When a multiple scan mode is enabled, this setting specifies the minimum time (in milliseconds) the scanner must wait before it can read the same barcode label again. This prevents accidental duplicate scans.

Enable target mode​

If enabled, when the scan button is pressed, the scanner will project an aiming pattern to assist in centering over the barcode before scanning. Tap Target mode to select the desired targeting behavior.

  • Spot Timeout: Scanning takes place after a programmable time upon pressing the scan button. Tap Target timeout to set the duration of the spot.

  • Release Scan: Scanning takes place after the scan button is released. Drag the Release scan timeout slider to set the scanning timeout after releasing the scan button.

  • Half Trigger: Enables the TrueAim™ two-stage trigger.

Decode timeout​

Drag the slider to set the maximum amount of time the scanner attempt to decode after target timeout (in case Spot Timeout is enabled) or after the scan button is pressed (in case Target mode is disabled).

Image decode timeout​

You can share any image (picture, jpg/png, etc.) with the Datalogic Service to try to decode it. Drag the Image decode timeout slider to set the decode timeout applied with image decoding.

Enable multi scan​

If selected, the scanner captures multiple labels sequentially.

Number of labels​

Drag the slider to indicate the amount of labels required for a code to be confirmed.

Enable single notification​

If selected, it enables indicators for each label, in order to get an intermediate notification for each label decoded.

Partial Results​

When multi scan mode is enabled, it selects the behavior when partial results are present.

OptionDescription
NeverThe decoding session is ended successfully and all the collected labels are returned together, only if the Number of Labels is reached.
Only on TimeoutThe decoding session is ended successfully and all the collected labels are returned together, only if the decode timeout has elapsed.
Only on ReleaseThe decoding session is ended successfully and all the collected labels are returned together, only if the trigger is released.
BothThe decoding session is ended successfully and all the collected labels are returned together if the trigger is released or the decode timeout has elapsed.

Presentation mode​

If enabled, the device starts to scan when motion is caught.

Aim control​

Enables the aimer while detecting motion.

Sensitivity​

Drag the slider to configure the motion detector's sensitivity.

External Scanner Source​

If enabled, allows barcode injection from an external scanner.

Standard Formatter Enable​

Executes the Standard Formatter on the injected barcodes.

Show Cropped Image​

The results of a barcode or OCR read may also include a cropped image of the data. These settings control its behavior.

Enable for Barcode​

Sends a cropped image for decoded barcode labels.

Enable for Snap OCR​

Shows the cropped image corresponding to the decoded OCR text.

Crop Margin​

Sets the amount of margin to add to all borders of the cropped image (0 - 100 pixels).

Entire Frame​

Sends the entire frame as the cropped image.

Scanning Preview​

While reading a barcode, a live preview of the image is displayed. Use these settings to control its behavior.

Note

This feature is not available on all devices.

General Options​

Source​

Selects the image source for the scan preview.

Activate while decoding​

Enables the preview automatically during barcode decoding.

Hide delay​

Sets the delay (0 - 5000 ms) before hiding the preview after decoding finishes.

Illumination source​

Selects the light source used for the preview.

Activate through SDK​

Allows the SDK to trigger and activate the preview.

Activate through broadcast intent​

Allows a broadcast intent to trigger and activate the preview.

Activate through proximity sensor​

Activates the preview automatically when an object is detected near the device.

Proximity low threshold​

Sets the minimum distance threshold (50 - 2000 mm) for proximity activation.

Proximity high threshold​

Sets the maximum distance threshold (50 - 2000 mm) for proximity activation.

Preview Positioning​

Preview display mode​

Selects how the preview is positioned on the display. The options are:

OptionDescription
Fit screenThe preview is centered and scaled to fill most of the display.
Manual positioningThe preview position and size are customized manually.
Portrait preview X​

Sets the X coordinate of the preview in portrait orientation.

Portrait preview Y​

Sets the Y coordinate of the preview in portrait orientation.

Portrait preview width​

Sets the width of the preview in portrait orientation.

Portrait preview height​

Sets the height of the preview in portrait orientation.

Landscape preview X​

Sets the X coordinate of the preview in landscape orientation.

Landscape preview Y​

Sets the Y coordinate of the preview in landscape orientation.

Landscape preview width​

Sets the width of the preview in landscape orientation.

Landscape preview height​

Sets the height of the preview in landscape orientation.

GS1 Evaluation​

Enable​

Enables GS1 label evaluation within the scan preview.

Remote address name​

Sets the server name or address to query when GS1 label values are missing from the barcode.

Remote address format​

Selects the URI format used to query the server. The options are:

OptionDescription
GTIN Inside PathThe GTIN is specified in the URI path (e.g., server.org/gtin/value).
GTIN Inside QueryThe GTIN is specified as a query parameter in the URI (e.g., server.org/?gtin=value).
Background color​

Sets the background color for GS1 evaluation results. Use AARRGGBB format (Hexadecimal: Alpha, Red, Green, Blue).

Text color​

Sets the text color for GS1 evaluation results. Use AARRGGBB format (Hexadecimal: Alpha, Red, Green, Blue).

Labels​

Manages GS1 labels (add, edit, or remove).
