MDM Migration

Overview​

A Scan2Deploy profile can move devices to a new MDM without touching each device. The same method covers both cases:

  • From one MDM to another, such as from SOTI MobiControl to Microsoft Intune.
  • From Android Device Administrator to Android Enterprise on the same MDM.

Your current MDM sends the device a Scan2Deploy profile with Enterprise Enrollment details for the new MDM. The profile performs an enterprise reset, and the device then enrolls in the new MDM in the Setup Wizard.

Migration erases the device

The enterprise reset erases all user data and apps, and removes the device from your current MDM. Back up any data on the devices that you need to keep before you start, and test the migration on a few devices first.

Minimum firmware​

Updating firmware

To update the devices from your current MDM, see Firmware Update.

The devices must meet the minimum firmware for both Enterprise Enrollment and Backup to enterprise.

Before you begin​

  • Update the devices to a firmware version that supports both features in the tables above.
  • Create an enrollment profile in the new MDM. See MDM enrollment profile.
  • Keep the devices enrolled in your current MDM, which sends the migration profile.

Create the migration profile​

Barcode Only profile

The migration profile is a Barcode Only profile.

Select the actions

  1. Open Scan2Deploy Studio.
  2. On the Welcome page, select Create Profile.
  3. On the Action Selection page, select the device Model, SKU, and OS Version.
  4. Under Configuration Actions, select Barcode Only.
  5. Select Enterprise Enrollment. Wi-Fi Setup is selected by default. Keep it selected, so the devices can connect to Wi-Fi and enroll in the new MDM after the reset.
  6. Select the > arrow.

Set up Wi-Fi

  1. On the Wi-Fi Setup page, under Defined Networks, set Availability to Always.
  2. Enter the network name in SSID.
  3. Select the Encryption Mode.
  4. Enter the Password.
  5. Select the > arrow.

See Wi-Fi Setup for enterprise (EAP) networks and the other Wi-Fi settings.

Set up enrollment in the new MDM

  1. On the Enterprise Enrollment page, open the Select an EMM list.
  2. Select the new MDM, or Other if it isn't listed.
  3. In Admin Extras Bundle, enter the values from the new MDM's enrollment profile, such as the enrollmentId for SOTI MobiControl.
  4. On the EMM Agent tab, check the Device admin component name, Device admin package download location, and Device admin signature checksum against your MDM's documentation. These are filled in automatically for listed MDMs.
  5. Select the > arrow.

See Enterprise Enrollment for the other enrollment settings.

Set the Save and Scan settings

  1. On the Save and Scan page, select the Settings tab.
  2. Under Final Action, open the Action list.
  3. Select Enterprise Reset.
  4. Under Deployment Settings, select Backup to enterprise, so the profile is kept through the enterprise reset and the device enrolls in the new MDM.
  5. Under Scan2Deploy QR Code Settings, check that Version is set to V3.
  6. Select Silent Deploy.
  7. Select Save.
  8. Select Copy.
  9. Copy the data for your current MDM:
    • SOTI MobiControl, SureMDM, and Workspace ONE: Select EMM Intent, then select your MDM (SOTI MobiControl, SureMDM, or Airwatch Intelligent Hub).
    • Microsoft Intune: Select Profile Data, then select Encrypted data.

See Final Action and Deployment Settings for more details on these settings.

Apply the profile​

Send the profile to the devices from your current MDM by following Deploy the profile on the Barcode Only page, which has the steps for each MDM.

Each device then:

  1. Applies the profile.
  2. Performs an enterprise reset, which removes the current MDM.
  3. Enrolls in the new MDM in the Setup Wizard.

Once the devices appear in the new MDM, remove them from your current MDM.
