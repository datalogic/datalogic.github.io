Configuration

Overview​

Datalogic-specific settings, such as scanner, keyboard, power, and system settings, are configured through Datalogic OEMConfig. Add the OEMConfig app from managed Google Play in your MDM, then create a managed configuration for it and assign it to your devices.

  • SOTI MobiControl
  • Microsoft Intune
  • SureMDM
  • Workspace ONEWorkspace ONE (formerly AirWatch)

These steps are based on SOTI's Using the Datalogic OEMConfig with Android Enterprise Devices guide.

Prerequisites

Your Datalogic devices must be enrolled as Android Enterprise Work Managed devices running Android 9 or later. Your SOTI MobiControl deployment must also be connected to managed Google Play.

  1. Sign in to the SOTI MobiControl web console.
  2. Select Policies from the main menu.
  3. Select Apps.
  4. Select New App Policy.
  5. Select Android.
  6. Select Android Enterprise.
  7. Select the Managed Google Play app source.
  8. Select the Google enterprise binding associated with your devices.
  9. Select Next.
  10. Select Add to open managed Google Play.
  11. Search for Datalogic OEMConfig.
  12. Select Datalogic OEMConfig from the search results.
  13. Select Approve to approve the application for your organization.
  14. Return to the SOTI MobiControl console.
  15. Select Synchronize if Datalogic OEMConfig is not displayed in the app list.
  16. Select Datalogic OEMConfig.
  17. Select Next.
  18. Set the deployment type to Mandatory so the application is installed automatically.
  19. Select Save to add the application to the app policy.
  20. Select Save and Assign.
  21. Select the device group to which the policy should be assigned.
  22. Confirm the assignment.
  23. Navigate to Policies.
  24. Select Profiles.
  25. Select New Profile.
  26. Select Android Enterprise as the platform.
  27. Enter a name for the profile.
  28. Open the Configurations tab.
  29. Select Add Configuration.
  30. Under Email & Others, select OEM Config.
  31. Select Datalogic.
  32. Expand the configuration groups containing the settings you want to manage.
  33. Configure the required Datalogic settings.
  34. Select Save.
  35. Assign the profile to the intended device group.
  36. Save the profile assignment.
  37. Verify that the profile is assigned to the devices.

These steps are based on Microsoft's Use and manage Android Enterprise devices with OEMConfig in Microsoft Intune guide.

Prerequisites

Your Intune tenant must be connected to managed Google Play. Your Datalogic devices must support Android Enterprise and be enrolled in Intune. You Intune user also needs permission to manage mobile apps and device configurations.

Add Datalogic OEMConfig to Intune

  1. Open a web browser and go to the Microsoft Intune admin center.
  2. Sign in with your Intune administrator account.
  3. Select Apps.
  4. Select All apps.
  5. Select Create or Add, depending on the console layout.
  6. Select Managed Google Play app as the app type.
  7. Select Select to open managed Google Play.
  8. Search for Datalogic OEMConfig.
  9. Select Datalogic OEMConfig from the search results.
  10. Select Approve.
  11. Confirm the approval if prompted.
  12. Close the managed Google Play window or return to the Intune admin center.
  13. Select Sync to synchronize managed Google Play apps with Intune.
  14. Wait for the synchronization to complete.
  15. Navigate to Apps > All apps.
  16. Select Datalogic OEMConfig.
  17. Select Properties.
  18. Under Assignments, select Edit.
  19. Under Required, select Add group.
  20. Select the device group that should receive Datalogic OEMConfig.
  21. Select Select.
  22. Select Review + save.
  23. Select Save.

Create the OEMConfig configuration profile

  1. Select Devices.
  2. Select Manage devices.
  3. Select Configuration.
  4. Select Create.
  5. Select New policy.
  6. Under Platform, select Android Enterprise.
  7. Under Profile type, select OEMConfig.
  8. Select Create.
  9. In the Name field, enter a name for the profile (for example, Datalogic OEMConfig).
  10. Optionally, enter a description.
  11. Select Select an OEMConfig app.
  12. Select Datalogic OEMConfig from the associated app list.
  13. Select Select.
  14. Select Next.
  15. Under Configuration settings, select Configuration designer.
  16. Expand the available configuration groups.
  17. Configure the desired Datalogic settings.
  18. Select Next.
  19. Optionally, select Add to configure scope tags.
  20. Select Next.
  21. Under Assignments, select Add groups.
  22. Select the device groups that should receive the configuration profile.
  23. Select Select.
  24. Select Next.
  25. Review the profile settings and assignments.
  26. Select Create.

These steps are based on SureMDM's Configure OEMConfig Policy Profile guide.

Prerequisites

Your Datalogic devices must be enrolled in SureMDM using Android Enterprise in Profile Owner or Device Owner mode and connected to managed Google Play.

  1. Sign in to the SureMDM web console.
  2. Navigate to Profiles.
  3. Select the Android tab.
  4. Select Add.
  5. Under Primary Profile, select OEMConfig Policy.
  6. Select Configure.
  7. Enter a name for the profile.
  8. Select DataLogic OEMConfig from the available applications.
  9. Configure the desired Datalogic settings.
  10. Select Save to create the profile.
  11. Return to the Home tab.
  12. Select the target device or devices.
  13. Select Apply to open the profile assignment prompt.
  14. Select the newly created OEMConfig profile.
  15. Select Apply to deploy the configuration.
  16. Verify that the configuration has been applied to the devices.

These steps are based on Omnissa's OEMConfig on Android Enterprise Devices guide.

Prerequisites

Your Workspace ONE UEM environment must be configured for Android Enterprise and connected to managed Google Play.

Add Datalogic OEMConfig to Workspace ONE UEM

  1. Sign in to the Workspace ONE UEM console.
  2. Select the Organization Group that manages your devices.
  3. Navigate to Resources > Apps > Native.
  4. Select the Public tab.
  5. Select Add Application.
  6. Set Platform to Android.
  7. Set Source to Search App Store.
  8. Enter Datalogic OEMConfig as the application name.
  9. Select Next to open managed Google Play.
  10. Search for Datalogic OEMConfig.
  11. Select the application and approve it if prompted.
  12. Select Save & Assign.

Configure and assign Datalogic OEMConfig

  1. On the assignment configuration page, open the Application Configuration tab.
  2. Enable Send Configuration.
  3. Configure the desired Datalogic settings using the available configuration options.
  4. Open the Assignment Groups section.
  5. Select the Smart Groups that should receive the configuration.
  6. Configure any additional assignment settings required for your deployment.
  7. Select Save & Publish.
  8. Review the assigned devices in the preview.
  9. Select Publish to deploy the application and configuration.
  10. Verify that Datalogic OEMConfig is installed and the configuration has been applied to the target devices.
