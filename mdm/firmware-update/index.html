Firmware Update

Overview​

Firmware files can be found on our Shield Firmware Website An update can be installed from a local OTA package pushed to the device, or downloaded automatically by Arrow FOTA.

  • SOTI MobiControl
  • Microsoft Intune
  • SureMDM
  • Workspace ONEWorkspace ONE (formerly AirWatch)

These steps are based on SOTI's Using File Sync Policies guide and its Datalogic firmware upgrade guide.

  1. In the SOTI MobiControl console, navigate to Policies > File Sync.
  2. Create a new File Sync policy.
  3. Select Download From Server as the sync type.
  4. Upload the firmware OTA ZIP file.
    1. SOTI no longer supports firmware files larger than 2 GBs, as such devices with firmware larger than 2 GBs will need to use the smaller incremental OTAs.
  5. Set the device destination path to /sdcard/Download/ota.zip, using the actual firmware filename if different.
  6. Configure the policy's Post-Sync Script with the following command, replacing ota.zip with the actual firmware filename: 
    sendintent -s "intent:#Intent;component=com.datalogic.systemupdate/com.datalogic.systemupdate.SystemUpgradeService;i.action=2;S.path=/sdcard/Download/ota.zip;i.reset=0;i.reboot=1;i.force_update=1;end"
  7. Enable Execute Script Only if Files Transmitted so the update command runs only when files are transferred.
  8. Configure the synchronization schedule.
  9. Select Save and Assign and assign the policy to the target devices or device group.
  10. Verify that the firmware file is transferred and the device completes the update.

These steps are based on Datalogic's Firmware Update OEMConfig documentation, our Intune firmware update guide, and Microsoft's Azure Blob Storage documentation.

Create an Azure Storage Account

  1. Sign in to the Azure portal.
  2. Search for Storage accounts.
  3. Select Create.
  4. Select the subscription and resource group to use, or create a new resource group.
  5. Enter a unique storage account name.
  6. Select the appropriate region and leave the remaining settings at their defaults unless your organization's requirements dictate otherwise.
  7. Select Review.
  8. Select Create.
  9. Once deployment completes, select Go to resource.

Create a public blob container

  1. In the Storage Account, navigate to Settings > Configuration.
  2. Set Allow Blob anonymous access to Enabled and select Save. This setting may be prohibited by your organization's security policy.
  3. Navigate to Data storage > Containers.
  4. Select + Container.
  5. Enter a name, such as firmware.
  6. Set the Anonymous access level to Blob (anonymous read access for blobs only).
  7. Select Create.

Upload the firmware package

  1. Open the firmware container.
  2. Select Upload.
  3. Select Browse for files and choose the downloaded firmware OTA ZIP.
  4. Select Upload.
  5. Select the uploaded blob and copy its URL. It should follow this format: https://<storage-account>.blob.core.windows.net/firmware/<firmware-filename>.zip.
  6. Open the URL in a private browser window to verify that the file is publicly downloadable without authentication.

Configure Datalogic OEMConfig in Intune

  1. Sign in to the Microsoft Intune admin center.
  2. Navigate to Devices > Manage devices > Configuration.
  3. Select Create > New policy.
  4. Select Android Enterprise as the platform.
  5. Select OEMConfig as the profile type.
  6. Enter a name, such as Datalogic Firmware Update.
  7. Select Next.
  8. Under Configuration settings, open Firmware Update.
  9. Set OTA update file to the complete Azure Blob URL copied earlier.
  10. Set Reset type to the required option. Select None to avoid requesting a reset after the firmware update, unless your deployment requires another reset type.
  11. Select Next.
  12. Assign the profile to the device group containing the target Datalogic devices.
  13. Select Next through the remaining configuration pages.
  14. Select Create.

These steps are based on SureMDM's Firmware Upgrade guide.

Create the firmware File Transfer job

  1. Sign in to the SureMDM console.
  2. Navigate to Jobs.
  3. Select New Job.
  4. Select Android.
  5. Select File Transfer.
  6. Select Add, then select the upload icon.
  7. Upload the firmware ZIP file and select OK.
  8. Enter a job name, such as Datalogic_Firmware.
  9. Save the job.

Create the Run Script job to start the firmware update

  1. Navigate to Jobs > New Job.
  2. Select Android.
  3. Select Run Script.
  4. Enter a job name, such as Upgrade Datalogic firmware.
  5. Enter the following script: 
     am startservice -n com.datalogic.systemupdate/com.datalogic.systemupdate.SystemUpgradeService --ei action 2 -e path sdcard/firmware.zip
  6. Save the job.

Create and apply a Composite Job

  1. Navigate to Jobs > New Job.
  2. Select Android.
  3. Select Composite Job and select Add.
  4. Add the two jobs in this order:
    1. Datalogic_Firmware (File Transfer).
    2. Upgrade Datalogic firmware (Run Script).
  5. Save the Composite Job.
  6. Return to the SureMDM Home page and select the enrolled device or target devices.
  7. Select Apply.
  8. Select the Composite Job and apply it.
  9. Verify that the firmware update completes successfully.

These steps are based on Omnissa's Managing Android OS Upgrades with Workspace ONE UEM guide.

Create the OS Upgrade File/Actions component

  1. Sign in to the Workspace ONE UEM console.
  2. Navigate to Devices > Provisioning > Components > Files/Actions.
  3. Select Add Files/Actions.
  4. Select Android.
  5. Enter a name, such as Datalogic Firmware Update.
  6. Select the Files tab.
  7. Select Add Files.
  8. Select Choose Files and upload the firmware OTA ZIP.
  9. Set the Download Path to osupdateosupdateosupdate/ota.zip, replacing ota.zip with the actual firmware filename.
  10. Select Save.
  11. Select the Manifest tab.
  12. Under Install Manifest, select Add Action.
  13. Select OS Upgrade.
  14. Select the uploaded firmware ZIP file.
  15. Select Save to save the Files/Actions component.

Create and assign the product

  1. Navigate to Devices > Provisioning > Product List View.
  2. Select Add Product.
  3. Select Android.
  4. Enter a product name, such as Datalogic Firmware Update.
  5. Configure the target Smart Group and assignment rules.
  6. Select the Manifest tab.
  7. Select Add.
  8. Select File/Action - Install from the Action(s) To Perform list.
  9. Select the Files/Actions component created earlier.
  10. Configure any required deployment conditions and dependencies.
  11. Select Save.
  12. Select Publish and confirm the assignment.
  13. Monitor the product deployment status in Workspace ONE UEM.
  14. Verify that the device installs the update, reboots if required, and reports the expected build number.
