Enrollment

Overview​

Enrollment links a device to your MDM and installs the MDM agent, also called the Device Policy Controller (DPC). On fully managed and dedicated devices, the DPC becomes the device owner and manages the entire device. With a work profile, the DPC becomes the profile owner and manages only the work profile.

Before enrolling devices, create an enrollment profile in your MDM. The profile sets the management use case and provides the enrollment details used by each enrollment method.

MDM enrollment profile​

  • SOTI MobiControl
  • Microsoft Intune
  • SureMDM
  • Workspace ONEWorkspace ONE (formerly AirWatch)

These steps are based on SOTI's Creating an Android Enterprise Device Policy guide and Device Side Actions for Enrollment guide.

Prerequisites

Your SOTI MobiControl deployment must have Android Enterprise configured and connected to managed Google Play before enrolling Android Enterprise devices.

Create the enrollment policy

  1. Sign in to the SOTI MobiControl web console.
  2. Navigate to Policies > Enrollment > All Policies.
  3. Select New Enrollment Policy.
  4. Select Google > Android Enterprise as the device family.
  5. On the General tab, enter a name and description for the policy (for example, Datalogic Work Managed).
  6. Select the enterprise binding linked to your managed Google Play account.
  7. Select Next.
  8. On the Device Type tab, select Work Managed.
  9. Select Next.
  10. On the Groups tab, select the authentication required to enroll: No authentication, Password, or Directory.
  11. Select the device group to which enrolled devices will be assigned.
  12. Select Next.
  13. On the Settings tab, select any additional settings required by your organization.
  14. Select Finish.
  15. On the Enrollment Policy Info page, note the Enrollment ID and enrollment URL.
  16. Select OK.

Use the following admin extras with the enrollment method below:

  • enrollmentId: the Enrollment ID from the enrollment policy

These steps are based on Microsoft's Set up Intune enrollment for Android Enterprise dedicated devices guide.

Prerequisites
  • Your Intune tenant must be connected to managed Google Play. See the requirements in Microsoft's guide.
  • Devices must run Android 8.0 or later and have Google Mobile Services (GMS).
  1. Open a web browser and go to the Microsoft Intune admin center.
  2. Sign in with your Intune administrator account.
  3. Select Devices.
  4. Under Device onboarding, select Enrollment.
  5. Select the Android tab.
  6. Under Enrollment Profiles, select Corporate-owned dedicated devices.
  7. Select Create profile.
  8. In the Name field, enter a name for the profile (for example, Datalogic Dedicated). Write this name down; it can be used later to group the enrolled devices.
  9. Optionally, enter a Description.
  10. Under Token type, select Corporate-owned dedicated device (default).
  11. Set the Token expiration date.
  12. Optionally, set Apply device name template to Yes and enter a naming template (for example, DL-{{SERIAL}}).
  13. Select Next.
  14. Optionally, on the Device group page, select Search by group name and choose a static device group for the enrolled devices.
  15. Select Next.
  16. Optionally, on the Scope tags page, add scope tags.
  17. Select Next.
  18. On the Review + create page, check the summary and select Create.
  19. Select the new profile in the list.
  20. Select Token to view the enrollment token.

Use the following admin extras with the enrollment method below:

  • com.google.android.apps.work.clouddpc.EXTRA_ENROLLMENT_TOKEN: the enrollment token shown on the Token page
Grouping devices by enrollment profile

To target policies and apps at the enrolled devices, create a dynamic device group with the rule Property enrollmentProfileName Equals the profile name entered above.

These steps are based on 42Gears' How to Create a QR Code To Enroll Android Devices To SureMDM guide.

Prerequisites

Your SureMDM deployment must be enrolled with Android Enterprise before you can create an Android Enterprise enrollment QR code. See 42Gears' Android Enterprise enrollment guide.

  1. Sign in to the SureMDM web console.
  2. Navigate to Enrollment.
  3. Select List View.
  4. Select Create QR Code.
  5. In the Name field, enter a name for the enrollment configuration (for example, Datalogic Device Owner).
  6. Under Platform, select Android.
  7. Under Enrollment Type, select Android Enterprise Enrollment.
  8. Select Next.
  9. Select the device group to which enrolled devices will be assigned.
  10. Select the device naming option and configure the device name as required.
  11. Optionally, configure the QR code expiration date and maximum number of devices allowed to enroll.
  12. Open Provisioning Settings.
  13. Configure the provisioning options required by your organization.
  14. Select Save to save the provisioning settings.
  15. Optionally, configure the locale settings.
  16. Configure Wi-Fi credentials if the devices need Wi-Fi during provisioning.
  17. Configure mobile data or proxy settings if required.
  18. Select Next.
  19. Select Save.

Use the following admin extras with the enrollment method below:

  • AccountId: your SureMDM account ID
  • ServerPath: your SureMDM server path
  • GroupPath: the device group to which enrolled devices will be assigned
  • EnrollmentMode: 0 (Device Owner)

These steps are based on Omnissa's Configuring Work Managed Device Enrollment guide.

Prerequisites

Your Workspace ONE UEM environment must be registered with Google as an Android Enterprise EMM provider before enrolling fully managed devices.

  1. Sign in to the Workspace ONE UEM console.
  2. Select the organization group where the devices will be enrolled.
  3. Navigate to Devices > Lifecycle > Staging > List View.
  4. Select Configure Enrollment.
  5. Select Android.
  6. Select Custom DPC as the management type.
  7. Select Configure.
  8. In the Wi-Fi section, optionally configure the Wi-Fi network the devices will use during provisioning.
  9. Select Next.
  10. In the Hub section, select the latest Workspace ONE Intelligent Hub or specify an externally hosted Hub package.
  11. Select Next.
  12. In the Enrollment Details section, enable Configure Organization Group.
  13. Select the organization group where the devices will be enrolled.
  14. Configure the enrollment authentication settings required by your organization.
  15. Configure whether system applications should remain available on the fully managed devices.
  16. Select Next.
  17. Review the enrollment configuration.

Use the following admin extras with the enrollment method below:

  • serverurl: the Workspace ONE UEM device services server URL
  • gid: the Group ID of the organization group
  • un: the staging user name, if required
  • pw: the staging user password, if required

Android Enterprise enrollment​

Datalogic devices support the standard Android Enterprise enrollment methods: zero-touch, QR code, NFC, and manual DPC identifier. Each starts from a factory reset device in the Setup Wizard and uses the enrollment profile created above. Android Enterprise enrollment requires Google Mobile Services (GMS).

  • Zero-TouchZero-Touch (Recommended)
  • AE QR CodeAndroid Enterprise QR Code
  • NFC
  • Manual

Android zero-touch enrollment automatically enrolls devices in your MDM during initial setup. Simply power on the device and connect it to the internet using cellular data. If cellular connectivity is unavailable, connect to Wi-Fi instead.

Connecting to a network

WWAN devices with an active SIM card connect to the cellular network automatically. On WLAN devices, scan a Wi-Fi QR code with the built-in scanner to connect to Wi-Fi. Wi-Fi QR codes can be created with the Wi-Fi QR Code Generator.

Register the devices

  1. Purchase devices from an authorized zero-touch reseller, including directly from Datalogic.
  2. The reseller creates your organization's zero-touch account, if you don't already have one, and registers the devices to it.

Create a zero-touch configuration

These steps are based on Google's Create custom zero-touch configurations guide.

  1. Sign in to the zero-touch enrollment portal with your organization's account.
  2. Select Configurations.
  3. Select Add.
  4. In Configuration name, enter a name (for example, Datalogic Dedicated).
  5. Under EMM DPC, select the DPC for your MDM (see the table below).
  6. In DPC extras, paste the JSON with your MDM's enrollment details (see the table below).
  7. Optionally, enter the Company name, Support email address, Support phone number, and a Custom message. These are shown on the device during setup.
  8. Select Add.
  9. Optionally, under Default configuration, select the new configuration and select Apply, so that newly registered devices receive it automatically.

Protect your DPC extras

DPC extras can contain enrollment credentials. Share them only with administrators who manage your zero-touch account.

Assign the configuration and enroll

  1. In the zero-touch portal, select Devices.
  2. Find each device by IMEI or serial number and set its Configuration. To assign many devices at once, select More > Upload batch configurations and upload a CSV file.
  3. Power on the device (or factory reset it).
  4. Connect to a network, either cellular or Wi-Fi (scan a Wi-Fi QR code).
  5. The device downloads the MDM agent and enrolls automatically.

QR code enrollment uses an Android Enterprise enrollment QR code that contains the MDM agent download location and enrollment details. On Datalogic devices, the QR code can be scanned at any point in the Setup Wizard using the built-in scanner. There is no need to tap the Welcome screen six times or use the camera.

The QR code generated by your MDM can be scanned directly. To add Datalogic-specific settings, such as Wi-Fi, APN, and EAP settings, create the QR code with one of the Datalogic tools instead:

  • Datalogic Android Enterprise QR Code Generator: Includes predefined settings for many MDMs and can import and encrypt a QR code exported from your MDM. See Generate QR Code for details on each field.
  • Scan2Deploy Studio: The Enterprise Enrollment section of Scan2Deploy Studio can also generate Android Enterprise QR codes and embed enrollment details in a Scan2Deploy barcode.
  1. Create an enrollment profile in your MDM console and note the enrollment details (or export its QR code).
  2. Use the QR code from your MDM, or create one with the Android Enterprise QR Code Generator or Scan2Deploy Studio.
  3. On a factory reset device, scan the QR code from the Setup Wizard. The device downloads the MDM agent and enrolls.

NFC enrollment transfers the enrollment details from a programmer device to a factory reset Datalogic device with an NFC bump. It is available on Datalogic devices with NFC.

  1. On a separate Android device, install the NFC provisioning app provided by your MDM (for example, SOTI MobiControl Stage Programmer) and enter the enrollment details from your enrollment profile.
  2. Factory reset the Datalogic device and leave it on the Setup Wizard Welcome screen.
  3. Hold the two devices back to back until the programmer device confirms the transfer.
  4. Follow the on-screen prompts. The device connects to the network, downloads the MDM agent, and enrolls.

Manual enrollment is useful for small deployments or testing when zero-touch and QR code enrollment are not available. It requires Google Mobile Services (GMS) on the device.

Android Classic enrollment​

Legacy enrollment

Android Classic (device administrator) enrollment is supported only with SOTI MobiControl and may not be supported in the near future. Google has deprecated device administrator management; use Android Enterprise for new deployments.

  • SOTI MobiControl

On Datalogic devices, the SOTI MobiControl agent is preinstalled, so no download is needed during setup.

  1. In the SOTI MobiControl console, create an enrollment policy with Android Classic as the device family and note its Enrollment ID or QR code.
  2. Power on the device and complete the Setup Wizard.
  3. Open the SOTI MobiControl app on the device.
  4. Enter the enrollment ID, or scan the SOTI enrollment QR code.
  5. Follow the on-screen prompts and activate the device administrator when asked.
