Scan2Deploy Barcode Only

Overview​

A Barcode Only Scan2Deploy profile holds all of its data in the barcode itself, so there is no .tar file to host. Instead of scanning the barcode, your MDM sends the same data to the Scan2Deploy Agent on the device in an intent, and the agent applies the profile.

Barcode Only profiles support the following actions:

  • Wi-Fi Setup
  • Enterprise Enrollment
  • Applications (enable and disable apps only)
  • Device and Scanner Settings
  • Scripts
  • Scan2Deploy and Android settings

For any other action, such as installing apps or configuring Datalogic Launcher, use a Host Profile.

Before you begin​

Complete the steps in Scan2Deploy: Before you begin, and read What both have in common for how MDM-deployed profiles behave.

Create the profile​

  1. Open Scan2Deploy Studio.
  2. On the Welcome page, select Create Profile.
  3. On the Action Selection page, select the device Model, SKU, and OS Version.
  4. Under Configuration Actions, select Barcode Only.
  5. Select the actions to include in the profile.
  6. Select Next and configure each action.
  7. On the Save and Scan page, open the Settings section.
  8. Under Scan2Deploy QR Code Settings, check that Version is set to V3.
  9. Select Silent Deploy, so the profile is applied in the background without the Scan2Deploy Agent opening on the screen of a device that may be in use.
  10. Select Save.
  11. Select Copy.
  12. Copy the data for your MDM:
    • SOTI MobiControl, SureMDM, and Workspace ONE: Select EMM Intent, then select your MDM (SOTI MobiControl, SureMDM, or Airwatch Intelligent Hub). The intent is copied, formatted for your MDM.
    • Microsoft Intune: Select Profile Data, then select Encrypted data.

See Save and Scan for more details on the copy options.

Deploy the profile​

  • SOTI MobiControl
  • Microsoft Intune
  • SureMDM
  • Workspace ONEWorkspace ONE (formerly AirWatch)

These steps are based on SOTI's Sending Scripts to Devices guide. The SOTI MobiControl intent copied from Scan2Deploy Studio is a sendintent script command.

Send the profile to the devices

  1. Sign in to the SOTI MobiControl web console.
  2. Navigate to Devices.
  3. Select the target device or device group.
  4. Select Send Script.
  5. Select New Script.
  6. Set Script Type to Custom.
  7. Paste the SOTI MobiControl intent copied from Scan2Deploy Studio.
  8. Select Send.
  9. Verify that the profile is applied, either on the device or in the session status file /sdcard/Download/S2DStatus.log.

Intune can't send intents or run scripts on Android Enterprise devices. Instead, use the Launch Activities setting of Datalogic OEMConfig to open the Scan2Deploy Agent with the profile data, using the start activity intent.

One OEMConfig profile per device

Intune supports only one OEMConfig profile per device on Datalogic devices. Add the launch activity to your existing OEMConfig profile from OEMConfig, rather than creating a new profile.

Add the launch activity to the OEMConfig profile

  1. Sign in to the Microsoft Intune admin center.
  2. Select Devices.
  3. Select Manage devices.
  4. Select Configuration.
  5. Select your Datalogic OEMConfig profile.
  6. Select Properties.
  7. Next to Configuration settings, select Edit.
  8. Select Configuration designer.
  9. Expand Launch Activities.
  10. Set Package Name to com.datalogic.scan2deploy.
  11. Set Component Name to com.datalogic.scan2deploy.MainActivity.
  12. Under Launch Activity Extras, select Add.
  13. Set Extra Type to String.
  14. Set Extra Name to data.
  15. Set Extra Value to the encrypted data copied from Scan2Deploy Studio.
  16. Select Review + save.
  17. Select Save.
  18. Verify that the profile is applied, either on the device or in the session status file /sdcard/Download/S2DStatus.log.

These steps are based on 42Gears' Jobs for Android guide. The SureMDM intent copied from Scan2Deploy Studio is a SureMDM script command.

Create the Run Script job

  1. Sign in to the SureMDM web console.
  2. Navigate to Jobs.
  3. Select New Job.
  4. Select Android.
  5. Select Run Script.
  6. Enter a job name, such as Scan2Deploy Profile.
  7. Paste the SureMDM intent copied from Scan2Deploy Studio.
  8. Select Save.

Apply the job

  1. Return to the Home tab.
  2. Select the target device or devices.
  3. Select Apply.
  4. Select the Scan2Deploy Profile job.
  5. Select Apply.
  6. Verify that the profile is applied, either on the device or in the session status file /sdcard/Download/S2DStatus.log.

These steps are based on Omnissa's Product Provisioning documentation. The Airwatch Intelligent Hub intent copied from Scan2Deploy Studio is used in a Run Intent action.

Create the product

  1. Sign in to the Workspace ONE UEM console.
  2. Navigate to Devices > Provisioning > Product List View.
  3. Select Add Product.
  4. Select Android.
  5. On the General tab, enter a Name, such as Scan2Deploy Profile.
  6. In Assigned Groups, select the Smart Groups that should receive the profile.
  7. Select the Manifest tab.
  8. Select Add.
  9. Select Run Intent from the Action(s) To Perform list.
  10. Paste the Airwatch Intelligent Hub intent copied from Scan2Deploy Studio.
  11. Select Save.
  12. Select Save to save the product.

Activate the product

  1. Select Activate to preview the devices that will receive the profile.
  2. Select Activate again to start the deployment.
  3. Monitor the product deployment status in Workspace ONE UEM.
  4. Verify that the profile is applied, either on the device or in the session status file /sdcard/Download/S2DStatus.log.
